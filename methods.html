Algorithm and figure methods

The Evolution lab implements browser teaching profiles that expose the main mechanism of each selected Differential Evolution method. The Data Studio builds descriptive research figures from imported files.

Reproduction boundary. These compact browser profiles are not certified reference implementations or exact competition configurations. Population sizes and evaluation budgets are user configurable, several adaptation schedules are simplified, and no CEC benchmark suite is run. Use the original papers and validated reference code for formal experiments.

Shared DE implementation rules

  • The app minimizes Sphere, Rastrigin, or Rosenbrock on the selected dimension and function bounds.
  • Peer indices are sampled without replacement and exclude the target when the method permits.
  • Greedy one-to-one selection retains the lower objective value.
  • Out-of-bound values are reflected back into the feasible interval.
  • The evaluation budget includes initial population scoring and every trial evaluation. CoDE may end partway through its multi-trial generation.
  • The landscape is a 2D slice varying x₁ and x₂ while later coordinates are zero; candidate objectives use the full selected dimension.
  • Random choices use the visible seed. Changing settings starts a new run.

Research workflow and provenance

The Research Workflow tab assembles a reviewable analysis plan from the imported profile, stated research question, and selected visualization. It records source metadata (including a SHA-256 checksum where browser support permits), field profile, missing and duplicate counts, exploratory outlier-screening counts, chart fields and settings, researcher preprocessing/statistical-method notes, and a self-reported review checklist. The plan asks the researcher to verify extraction, units, study design, observation unit, preprocessing, and visualization fit.

This is a documentation aid. It does not validate data, verify checklist responses, run inferential statistics, or generate research claims. A checksum identifies the uploaded file bytes; it does not guarantee that extracted values or downstream analyses are correct.

Research figure methods

The Data Studio profiles field types, missing cells, exact duplicate rows, numeric ranges, and category structure. Recommendations are a deterministic, rule-based ranker using source shape and the stated question. The plot builder supports line, area, scatter, bubble, bar, grouped bar, histogram, ECDF, box, correlation heatmap, Pareto, image intensity, table, concept-map, and process views.

Histograms use a Freedman–Diaconis bin-width estimate when quartiles and range allow it, with a bounded fallback of 5–60 bins. Box plots show min, first quartile, median, third quartile, and max. Correlation heatmaps show Pearson r with pairwise-complete values. These are descriptive summaries: no inferential test, confidence interval, imputation, or causal model is produced.

Source values remain available for export. Plots with more than 6,000 observations may use deterministic stride sampling to keep interaction responsive; exported CSV, TSV, JSON, Excel, and Figure JSON retain all imported rows. A plotted series is labeled when sampled. Sources are capped at 50,000 rows and 1,000,000 cells to protect browser memory; oversized inputs are flagged. Image profiling samples at most 10,000 pixels and is not a scientific image-segmentation method.
