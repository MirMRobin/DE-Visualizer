Algorithm reference

Methods and assumptions

The lab minimizes Sphere, Rastrigin, or Rosenbrock. The landscape is a 2D slice with later coordinates fixed at zero; candidate markers project the first two coordinates while the objective uses the full selected dimension.

Available methods: configurable DE; DE/rand/1/bin; DE/best/1/bin; DE/current-to-best/1/bin; DE/rand/2/bin; DE/current-to-rand/1; jDE; JADE; SHADE; L-SHADE; jSO; SaDE; CoDE; and EPSDE. Select a method in Evolution lab to see its mutation and parameter behavior. Classical named variants use fixed binomial crossover except current-to-rand/1, which uses its native no-crossover trial vector. Adaptive methods control their own parameters.

Implementation scope: these are compact browser teaching profiles for comparing the methods’ main mechanisms. Several methods use simplified parameter-update schedules and user-selected population sizes; they are not certified reference implementations or exact competition configurations. In particular, jSO uses a simplified staged weighting, SaDE learns strategy probabilities from recent outcomes, CoDE compares up to three trials per target, and EPSDE reinitializes failed parameter/strategy choices. Use the linked primary papers and validated reference code for formal reproduction.

All methods use greedy one-to-one selection and reflected bound repair. The evaluation budget counts each objective call, including initialization and all CoDE trial vectors. Therefore CoDE can stop partway through a generation when the remaining budget is smaller than its next set of trials.

Export and provenance

Take results with you

The data studio enables exports suited to the selected visual form: SVG and PNG for graphics; CSV or JSON for parsed data and chart series; Markdown, Mermaid, and OPML for mind maps and process diagrams; standalone HTML for shareable static reports. Browser-side analysis is local to this page. No input is uploaded.

Charts include data labels, axis names, and the selected purpose where applicable. Mind maps and workflows keep parent-child or step order. Use the export that preserves the meaning you need; image files are for sharing, structured files are for editing.
